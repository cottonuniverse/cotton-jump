# 🍄 Cotton Jump

Permainan platformer ringkas dalam pelayar — lompat, kutip syiling, hentak musuh, habiskan 3 level.

**▶️ Main di sini:** https://cottonuniverse.github.io/cotton-jump/

## Cara main
- **← →** gerak
- **SPACE / ↑** lompat
- Hentak atas musuh = +200 mata
- Kutip syiling = +100 mata
- Habis semua level dengan cepat = bonus mata

Boleh main di telefon juga (ada butang sentuh).

Dibina dengan HTML + JavaScript sahaja — satu fail, tiada apa nak install.
